# Robotbase

The batteries-included developer-experience layer for agent-driven robotics —
"Supabase for ROS 2" in feeling: the ROS 2 + Gazebo setup headache vanishes, and
coding agents get structured tools (MCP + CLI) to build, launch, inspect, and test a
robotics simulation project locally.

Local-first, open-core. No cloud, no accounts in the core.
