# Robotbase examples

Worked projects that go beyond the minimal scaffold `robotbase create` gives you.

## Challenges

Each is a complete Robotbase project with a deliberately-incomplete controller and scenarios
you make pass — a good way to learn the loop, and a good test for a coding agent.

- [`challenges/mobile-nav`](challenges/mobile-nav) — differential-drive: stop before an obstacle,
  reach a goal pose, navigate around a wall.
- [`challenges/drone-navigate`](challenges/drone-navigate) — quadrotor: fly to a 3-D point and hover.

Copy one anywhere and run `robotbase up` / `robotbase test <scenario>`.
